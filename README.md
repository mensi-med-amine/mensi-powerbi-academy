# MENSI Power BI Academy

An English-language Power BI learning and PL-300 practice website.

## Features
- 520 practice questions across four PL-300 domains
- 50-question exams, scored out of 1,000; 700 points to pass
- Correct answers, explanations, and exam history
- Simple learning topics, including DAX

## Run locally

Install Node.js 20 or newer, then open a terminal in this folder and run:

```bash
npm install
npm run install:all
npm run dev
```

Open **http://localhost:5173**. The API runs on **http://localhost:4000**.

This is an independent learning project, not an official Microsoft product. Questions are practice material, not official exam questions.
